# v0.15 — Server 도메인 구현 (FastAPI + PostgreSQL + REST API 7개)

- 일시: 2026-02-19
- 도메인: server, config

## 변경 요약

Phase 1 데이터 파이프라인 완성을 위한 Server 도메인 전체 구현. FastAPI 앱, PostgreSQL 연결, 공고 수신/조회 REST API 7개 엔드포인트, SQLAlchemy 모델, 비즈니스 서비스를 포함한다. Notion 연동은 Phase 4로 defer.

## API 엔드포인트

| Method | Path | 인증 | 설명 |
|--------|------|------|------|
| GET | `/api/health` | - | 헬스체크 |
| POST | `/api/announcements/batch` | API Key | 공고 일괄 등록 (upsert) |
| GET | `/api/announcements/stats` | - | 통계 조회 |
| GET | `/api/announcements/export` | - | CSV/XLSX 내보내기 |
| GET | `/api/announcements` | - | 목록 조회 (필터/정렬/페이징) |
| GET | `/api/announcements/{id}` | - | 상세 조회 |
| PATCH | `/api/announcements/{id}/status` | - | 상태 변경 |

## 인터페이스 영향

- 신규 7개 REST API 엔드포인트 (`/api` prefix)
- DB: `g2b.announcements` 테이블 자동 생성 (init_db)
- Agent → Server 배치 전송 수신 준비 완료
